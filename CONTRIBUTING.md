# Contributing to Vocard

Thank you for your interest in contributing to Vocard! We welcome contributions from the community.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/Vocard.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes: `npm test`
6. Commit your changes: `git commit -m "Add your feature"`
7. Push to your fork: `git push origin feature/your-feature-name`
8. Create a Pull Request

## Development Setup

1. Install dependencies: `npm install`
2. Copy environment file: `cp .env.example .env`
3. Configure your environment variables
4. Start development server: `npm run dev`

## Code Style

- Use TypeScript for all new code
- Follow the existing code style
- Add JSDoc comments for public APIs
- Write tests for new functionality
- Ensure all tests pass before submitting

## Pull Request Guidelines

- Provide a clear description of the changes
- Include tests for new functionality
- Update documentation if needed
- Ensure CI passes
- Keep commits focused and atomic

## Reporting Issues

- Use the GitHub issue tracker
- Provide detailed reproduction steps
- Include relevant logs and error messages
- Specify your environment (Node.js version, OS, etc.)
